Snowflake Credentials

Account Identifier Formats:
• abc12345 (account locator)
• orgname-accountname (organization format)
• abc12345.us-east-1 (with region)
• You can also enter the full URL (e.g., abc12345.snowflakecomputing.com) - it will be normalized automatically
Private Key Authentication:
• Requires an RSA private key file (PEM format)
• More secure than password authentication
• See documentation for key generation instructions
Configuration File:
• Supports JSON and TOML formats
• Store all credentials in a single file
• Ideal for managing multiple connections
• See documentation for file format examples
